# Overview

**Real And Unapologetic** is a podcast/talk show website built as a full-stack TypeScript application. It serves as a promotional landing page for the "Real And Unapologetic" show, featuring a hero section, about section, episodes listing, social media subscribe links, and a footer. The site supports light/dark theme toggling and is designed with a bold, modern aesthetic.

The project follows a monorepo structure with a React frontend (Vite), an Express backend, and a shared schema layer using Drizzle ORM with PostgreSQL.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Directory Structure
- `client/` — React frontend (Vite-based SPA)
- `server/` — Express backend API server
- `shared/` — Shared types and database schema (Drizzle ORM)
- `migrations/` — Database migrations generated by Drizzle Kit
- `script/` — Build scripts

### Frontend Architecture
- **Framework**: React 18 with TypeScript
- **Bundler**: Vite with HMR support in development
- **Routing**: Wouter (lightweight client-side router)
- **State Management**: TanStack React Query for server state
- **UI Components**: shadcn/ui (New York style) built on Radix UI primitives
- **Styling**: Tailwind CSS with CSS custom properties for theming, supporting light and dark modes
- **Animations**: Framer Motion for scroll-based and entrance animations
- **Icons**: Lucide React + react-icons (for brand icons like YouTube, Instagram)
- **Theme System**: Custom ThemeProvider using React context with localStorage persistence, defaulting to dark mode
- **Path Aliases**: `@/` maps to `client/src/`, `@shared/` maps to `shared/`

### Backend Architecture
- **Framework**: Express 5 (ESM)
- **Runtime**: Node.js with tsx for TypeScript execution
- **API Pattern**: RESTful endpoints under `/api` prefix
- **Episode Data**: Currently hardcoded in `server/routes.ts` as static data (not stored in DB)
- **Storage Layer**: Abstract `IStorage` interface with an in-memory implementation (`MemStorage`). This is ready to be swapped to a database-backed implementation.
- **Development Server**: Vite dev server is integrated as Express middleware during development
- **Production**: Static files served from `dist/public`; server bundled to `dist/index.cjs` via esbuild

### Data Storage
- **ORM**: Drizzle ORM configured for PostgreSQL
- **Schema**: Defined in `shared/schema.ts` using Drizzle's `pgTable` helpers
- **Current Schema**: A single `users` table with `id` (UUID, auto-generated), `username`, and `password` fields
- **Validation**: Zod schemas generated from Drizzle schema via `drizzle-zod`
- **Database Push**: Use `npm run db:push` to sync schema to database
- **Environment**: Requires `DATABASE_URL` environment variable for PostgreSQL connection
- **Note**: The current storage implementation (`MemStorage`) uses an in-memory Map, not the database. The DB infrastructure is set up but not actively wired into the storage class.

### Build System
- **Development**: `npm run dev` — runs tsx with Vite middleware for HMR
- **Production Build**: `npm run build` — Vite builds frontend to `dist/public`, esbuild bundles server to `dist/index.cjs`
- **Type Checking**: `npm run check` — runs TypeScript compiler in noEmit mode
- **Build Script**: Custom `script/build.ts` that bundles select server dependencies (allowlist) to reduce cold start times

### Page Structure
The app is a single-page landing site with these sections (all on the home page):
1. **Navbar** — Fixed navigation with smooth scroll links, theme toggle, YouTube link
2. **Hero Section** — Full-screen background image with CTA buttons
3. **About Section** — Feature cards describing the show's values
4. **Episodes Section** — Grid of episode cards linking to YouTube
5. **Subscribe Section** — Social media platform links (YouTube, Instagram, TikTok, Spotify)
6. **Footer** — Branding and social links

## External Dependencies

### Database
- **PostgreSQL** — Required via `DATABASE_URL` environment variable. Used with Drizzle ORM for schema management and `connect-pg-simple` for session storage capability.

### Third-Party Services & Links
- **YouTube** — Primary content platform (`https://www.youtube.com/@RealAndUnapologetic`). Episodes link to YouTube.
- **Instagram** — Social presence (`https://www.instagram.com/realandunapologetic/`)
- **TikTok & Spotify** — Placeholder links (set to `#`, not yet configured)

### Key npm Dependencies
- **Frontend**: React, Vite, Wouter, TanStack React Query, Tailwind CSS, shadcn/ui (Radix UI), Framer Motion, react-icons
- **Backend**: Express 5, Drizzle ORM, drizzle-zod, connect-pg-simple, express-session
- **Shared**: Zod for validation, drizzle-zod for schema-to-validation bridging
